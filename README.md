# Synaptique

> 知識を貯めるだけでなく、つなげることで初めて価値が生まれる。

アイデアをつなげるマインドマップアプリ。ノードを右方向に展開し、思考の流れを視覚化します。

**https://synaptique-dun.vercel.app/**

---

## 名前の由来

**Synaptique（シナプティック）** は、Synapse（シナプス）とフランス語の形容詞語尾 *-ique* を組み合わせた造語です。

脳のニューロン同士をつなぐ「シナプス」は、単体では意味を持たない情報同士が接続されることで、記憶・思考・理解という高次の機能を生み出す構造です。これは、断片的な知識やメモが互いにリンクし合うことで、新しい気づきや体系的な理解へと発展していく本アプリのコンセプトそのものです。

語尾に *-ique* を採用したのは、単なる直訳的な英単語ではなく、知的で洗練された響きを持たせるため。*classique*（古典的な）や *poétique*（詩的な）のように、対象の本質的な特徴を形容するこの語尾を通じて、「シナプスのようなアプリ」ではなく、**「知識が接続され、意味を持つ状態そのもの」** を指す言葉として選びました。

## 主な機能

### 自動整列（ロジックツリー）

Synaptique の中核機能。ロジックツリー型のシートでは、ノードの追加・削除・サイズ変更のたびに**左右展開レイアウト**へ自動で整頓されます（手動の整列ボタンはありません）。

- 親ノードを起点に、子・孫ノードが右方向へ世代ごとに整列
- 各親の子ノード群は縦方向に均等配置され、ツリー全体が視覚的に読みやすい構造に
- 下方向に追加したノードも右展開レイアウトへ自動合流

```
整列前（バラバラ）        整列後（自動整頓）

  ○   ○                 ○ ── ○ ── ○
    ○       ○    →      │
  ○   ○                 └── ○ ── ○
                               └── ○
```

### ノード編集

- **右＋ボタン** — 子ノードを追加（次の世代、右へ展開）
- **下＋ボタン** — 兄弟ノードを追加（同じ世代、同じ深さ）
- **ダブルクリック** — ラベルをインライン編集
- **カラー変更** — 6色からノードカラーを選択（紫・青・シアン・緑・ピンク・オレンジ）
- **メモ** — ノードごとにメモを追加
- **枠線・角丸・円形・サイズ** — ノードパネルから見た目を調整（文字だけのノードの枠線表示も切替可能）
- **画像** — クリップボードから画像を貼り付け、ノードに添付・自由配置の両方に対応（リサイズ・回転可）
- **削除** — ノード左上の削除ボタン

ノード追加時は既存ノードと重ならないよう自動で配置位置を調整します。右＋は右側へ、下＋は下側へ、それぞれ方向を維持したまま空きスペースを探します。

### Undo / Redo

編集操作を自動で履歴に記録し、元に戻す／やり直すができます（シート単位）。

### ホーム画面

ログイン後、まずホーム画面が表示されます。

- **マップ一覧** — カード形式でサムネイル付き一覧表示
- **スター** — お気に入りシートの固定表示
- **フォルダ** — シートをフォルダ分けして整理（フラット構造）
- **ゴミ箱** — 削除したシートを一時保管。復元・完全削除が可能
- **最近使用した項目** — 最終オープン日時で並び替え

### 複数シート

複数のマインドマップを1つのワークスペースで管理。シートの追加・ゴミ箱への移動・復元・完全削除・リネーム・スター・フォルダ移動に対応。

### 範囲選択・複数移動

空白エリアを左ドラッグすると選択ボックスが表示され、範囲内のノードを一括選択できます。選択後そのままドラッグで複数ノードをまとめて移動可能です。

### キャンバス操作

- ズームイン / ズームアウト
- 全体表示（fitView）
- 中クリック・右クリックドラッグでパン、マウスホイール・トラックパッドでズーム
- ミニマップで現在位置を確認

### その他

- **Googleログイン** — Supabase Auth による認証
- **データ永続化** — Zustand + localStorage（オフライン）／ Supabase（ログイン時に同期）
- **ダークモード** — OSの設定に自動追従、手動切替も可能
- **リセット確認** — 誤操作防止のカスタム確認ダイアログ
- **モバイル対応** — ホーム画面・画像貼り付けなどモバイル表示に対応

## セットアップ

```bash
npm install
```

Supabase の接続情報を `.env` に設定します：

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

## 開発サーバー起動

```bash
npm run dev
```

## ビルド

```bash
npm run build
```
